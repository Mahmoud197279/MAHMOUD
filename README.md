# Mahmoud Mostafa — AI Automation Portfolio

A bilingual (English/Arabic) Next.js portfolio starter for Mahmoud Mostafa, AI Automation Specialist.

## Included
- Dark visual system with blue accents
- Responsive landing page
- EN / AR language toggle and RTL layout
- Project cards with local screenshots from the supplied n8n workflows
- Case-study modal with challenge, approach, workflow overview and tools
- Contact links for email, LinkedIn and WhatsApp

## Run locally

Requirements: Node.js 20.9+ recommended.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build check

```bash
npm run build
```

## Deploy to Vercel
1. Create a GitHub repository and push this project.
2. Import the repository into Vercel.
3. Framework preset: Next.js; build command: `npm run build`.
4. Replace `metadataBase` in `src/app/layout.tsx` with the final deployed URL after deployment.
